## 🟥 C. 双向都缺:核心编辑器链路(最严重)

```
资源管理器能浏览文件夹
   ↓ 用户点 .py 文件  → ❌ 什么都没发生
中间空状态一直是 "CodeForge" + 快捷键说明,没编辑器 div
```

这条主链路完全没有:

```
点击文件 → agent.file.read(path) → 文本回显到中间区域 →
  用户编辑 → agent.file.change(path, content) → 标记 dirty →
  Ctrl+S 保存
```

## 📊 优先级建议(动手接 UI 时按这个顺序)

7. **default_path 渲染** (B-8)— 移动端提示
