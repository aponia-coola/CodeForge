如何让 CodeForge 自动切竖屏UI

已内置竖屏媒体查询示例，复制到 static/style.css 末尾即可。竖屏时三栏变单栏，文件树与Agent自动收成底栏/抽屉。

@media (max-width: 768px), (orientation: portrait) { .main{flex-direction:column} .sidebar, .right{width:100% !important; max-height:50vh} .sidebar-icons{flex-direction:row;width:100%;height:48px} .bottom-nav{display:flex} /* 将 .sidebar-icons 映射为底栏 */ .center{order:-1; min-height:42vh} .resize-handle{display:none} } /* WebView 注入：window.innerWidth < 768 时 JS 自动在 body 加 class="portrait" */
